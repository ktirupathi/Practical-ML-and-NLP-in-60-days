## Weekly Self-Assessment Rubric

After each week, answer these questions honestly:

1. **Can I explain every concept covered this week to someone else?** (Yes / Partially / No)
2. **Did I complete all coding exercises without looking at solutions first?** (Yes / Mostly / No)
3. **Can I apply these concepts to a new, unseen dataset?** (Yes / With guidance / No)
4. **Did I understand the mathematical intuition behind the algorithms?** (Yes / Partially / No)
5. **Am I confident answering interview questions on these topics?** (Yes / Partially / No)

**Scoring:** Yes = 2 points, Partially/Mostly = 1 point, No = 0 points

| Score | Recommendation |
|-------|---------------|
| 8-10 | Move to next week |
| 5-7 | Review weak areas, then proceed |
| 0-4 | Repeat the week before moving on |
