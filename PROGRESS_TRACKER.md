# 60-Day Progress Tracker

Use this checklist to track your progress through the Practical ML and NLP curriculum. Check off each day as you complete it.

---

## Phase 1: Foundation (Days 1-10)

Build a strong foundation in data handling, visualization, and core statistical concepts.

- [ ] **Day 1** - Python for Data Science Refresher: NumPy arrays, pandas DataFrames, and essential data manipulation operations.
- [ ] **Day 2** - Exploratory Data Analysis (EDA): Summary statistics, distributions, and identifying patterns in real-world datasets.
- [ ] **Day 3** - Data Visualization with Matplotlib and Seaborn: Creating informative plots including histograms, scatter plots, heatmaps, and pair plots.
- [ ] **Day 4** - Interactive Visualization with Plotly: Building interactive charts and dashboards for deeper data exploration.
- [ ] **Day 5** - Data Cleaning and Preprocessing: Handling missing values, outliers, duplicates, and inconsistent data formats.
- [ ] **Day 6** - Feature Engineering Fundamentals: Creating new features, encoding categorical variables, and scaling numerical features.
- [ ] **Day 7** - Probability and Statistics for ML: Hypothesis testing, confidence intervals, and statistical significance applied to data.
- [ ] **Day 8** - Linear Algebra Essentials for ML: Vectors, matrices, dot products, and their role in machine learning algorithms.
- [ ] **Day 9** - Data Pipelines with pandas: Method chaining, groupby operations, merging datasets, and building reproducible workflows.
- [ ] **Day 10** - Foundation Capstone: End-to-end EDA project on a large dataset with full cleaning, visualization, and statistical analysis.

---

## Phase 2: Machine Learning (Days 11-20)

Learn core supervised and unsupervised learning algorithms and evaluation techniques.

- [ ] **Day 11** - Linear Regression: Simple and multiple regression, assumptions, coefficient interpretation, and residual analysis.
- [ ] **Day 12** - Logistic Regression: Binary classification, sigmoid function, decision boundaries, and probability calibration.
- [ ] **Day 13** - Decision Trees and Random Forests: Tree-based models, feature importance, overfitting, and ensemble methods.
- [ ] **Day 14** - Gradient Boosting with XGBoost: Boosting fundamentals, XGBoost implementation, and hyperparameter tuning.
- [ ] **Day 15** - LightGBM and CatBoost: Efficient gradient boosting, handling categorical features natively, and performance comparison.
- [ ] **Day 16** - Model Evaluation and Validation: Cross-validation, confusion matrices, ROC-AUC, precision-recall, and metric selection.
- [ ] **Day 17** - Hyperparameter Tuning with Optuna: Bayesian optimization, search spaces, pruning, and automated tuning workflows.
- [ ] **Day 18** - Clustering Algorithms: K-Means, DBSCAN, hierarchical clustering, silhouette analysis, and cluster validation.
- [ ] **Day 19** - Dimensionality Reduction: PCA, t-SNE, UMAP, and their applications in visualization and preprocessing.
- [ ] **Day 20** - ML Capstone: Full classification or regression pipeline with feature engineering, model comparison, and evaluation.

---

## Phase 3: Advanced ML Pipelines (Days 21-30)

Build production-quality machine learning pipelines with experiment tracking and data validation.

- [ ] **Day 21** - Scikit-learn Pipelines: Building end-to-end pipelines with transformers, estimators, and column transformers.
- [ ] **Day 22** - Custom Transformers: Writing reusable custom transformers compatible with scikit-learn pipelines.
- [ ] **Day 23** - Feature Selection Methods: Filter, wrapper, and embedded methods for selecting the most informative features.
- [ ] **Day 24** - Handling Imbalanced Data: Oversampling, undersampling, SMOTE, class weights, and evaluation strategies for imbalanced datasets.
- [ ] **Day 25** - Experiment Tracking with MLflow: Logging parameters, metrics, and artifacts; comparing runs and managing model versions.
- [ ] **Day 26** - Data Validation with Great Expectations: Defining expectations, validating data quality, and integrating checks into pipelines.
- [ ] **Day 27** - Model Serialization and Deployment Prep: Saving and loading models with joblib and pickle, versioning, and reproducibility.
- [ ] **Day 28** - Building a REST API with FastAPI: Serving ML model predictions through a FastAPI endpoint with input validation.
- [ ] **Day 29** - Interactive ML Apps with Streamlit: Building a web application for model exploration and prediction visualization.
- [ ] **Day 30** - Pipeline Capstone: End-to-end ML pipeline with data validation, experiment tracking, and API deployment.

---

## Phase 4: NLP Foundations (Days 31-40)

Master the fundamentals of natural language processing from text preprocessing to classical NLP techniques.

- [ ] **Day 31** - Text Preprocessing: Tokenization, lowercasing, stopword removal, stemming, and lemmatization with NLTK and spaCy.
- [ ] **Day 32** - Text Representation: Bag-of-words, TF-IDF vectors, and n-gram models for converting text to numerical features.
- [ ] **Day 33** - Text Classification: Building text classifiers using TF-IDF features with logistic regression and naive Bayes.
- [ ] **Day 34** - Sentiment Analysis: Analyzing sentiment in product reviews and social media data using classical and lexicon-based approaches.
- [ ] **Day 35** - Named Entity Recognition (NER): Extracting entities from text using spaCy and training custom NER models.
- [ ] **Day 36** - Topic Modeling: Discovering topics with Latent Dirichlet Allocation (LDA) and visualizing topic distributions.
- [ ] **Day 37** - Text Similarity and Search: Computing document similarity using cosine similarity, Jaccard index, and TF-IDF vectors.
- [ ] **Day 38** - Regular Expressions for NLP: Pattern matching, text extraction, and data cleaning with regex in Python.
- [ ] **Day 39** - Working with the Hugging Face Datasets Library: Loading, filtering, mapping, and streaming large text datasets efficiently.
- [ ] **Day 40** - NLP Foundations Capstone: Multi-class text classification project with full preprocessing, feature engineering, and model comparison.

---

## Phase 5: Transformers and Embeddings (Days 41-50)

Dive into transformer-based models, embeddings, and modern NLP techniques.

- [ ] **Day 41** - Introduction to Word Embeddings: Word2Vec, GloVe, and understanding distributed word representations.
- [ ] **Day 42** - Sentence Transformers: Generating sentence-level embeddings and computing semantic similarity with sentence-transformers.
- [ ] **Day 43** - Hugging Face Transformers Quickstart: Loading pretrained models and tokenizers for text classification and generation.
- [ ] **Day 44** - Fine-tuning a Transformer for Classification: Fine-tuning a BERT-based model on a custom text classification dataset.
- [ ] **Day 45** - Text Summarization with Transformers: Extractive and abstractive summarization using pretrained sequence-to-sequence models.
- [ ] **Day 46** - Question Answering with Transformers: Building an extractive QA system using a pretrained transformer model.
- [ ] **Day 47** - Vector Databases with FAISS: Indexing and searching dense embeddings at scale using Facebook AI Similarity Search.
- [ ] **Day 48** - Vector Databases with ChromaDB: Storing, querying, and managing embeddings with metadata using ChromaDB.
- [ ] **Day 49** - Retrieval-Augmented Generation (RAG) Foundations: Combining retrieval from a vector store with generative models for grounded answers.
- [ ] **Day 50** - Transformers Capstone: Semantic search engine over a large document corpus with transformer embeddings and vector retrieval.

---

## Phase 6: Capstone and Production (Days 51-60)

Bring everything together with advanced projects, production practices, and a final capstone.

- [ ] **Day 51** - Advanced Feature Engineering for NLP: Combining TF-IDF, embeddings, and handcrafted features for improved model performance.
- [ ] **Day 52** - Multi-label and Multi-task NLP: Handling multiple labels per sample and training models for multiple objectives simultaneously.
- [ ] **Day 53** - Model Interpretability and Explainability: Using SHAP, LIME, and attention visualization to explain model predictions.
- [ ] **Day 54** - Bias Detection and Fairness in ML: Identifying and measuring bias in datasets and models, and applying mitigation strategies.
- [ ] **Day 55** - Scalable Data Processing: Processing large datasets efficiently with chunking, Dask, and optimized pandas operations.
- [ ] **Day 56** - Testing ML Code with Pytest: Writing unit tests, integration tests, and data tests for machine learning pipelines.
- [ ] **Day 57** - Containerization Basics for ML: Packaging ML applications with Docker for reproducible and portable deployments.
- [ ] **Day 58** - CI/CD for ML Projects: Setting up continuous integration pipelines with GitHub Actions for automated testing and validation.
- [ ] **Day 59** - Full-Stack ML Application: Building a complete application with a Streamlit frontend, FastAPI backend, and ML model serving.
- [ ] **Day 60** - Final Capstone: End-to-end NLP project from raw data to deployed application, combining all skills from the 60-day journey.
